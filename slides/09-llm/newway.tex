\begin{frame}{LM reasoning in 2026}

\vfill

\begin{itemize}
    \item Instead of using prompting, LMs are trained to
    reason.

\item Supervised finetuning (SFT)
\item Reinforcement learning (RL)
\item Training data: 
\begin{itemize}
\item Complex pipeline to create reasoning-relevant web
  corpus
\item Data generated by LM, then automatically labeled
\end{itemize}
\item Motivation 1: Instead of requiring prompts, LMs should become native reasoners.
%\item Motivation 2: We need lots of data for training, so we
%    need synthetic data generation.
    \item Motivation 2: Human-curated data limit the
    reasoning power. RL may discover novel and more diverse
    ways of reasoning.
\item Motivation 3: Inference-time scaling. \cotpfull fixes
    the length, not applicable to really hard problems that
    require flexible reasoning.
\end{itemize}

\vfill

\end{frame}
